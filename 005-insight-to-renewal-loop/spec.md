# Feature Spec: Insight → Renewal Loop

**Phase**: `005-insight-to-renewal-loop`  
**Depends on**: `002` M5–M7  
**Status**: Spec scaffold

Connect recommendation → experiment → billing/executive report into one visible thread for CSMs and renewals.

## Acceptance

- From a recommendation, user can create an experiment in one click
- Experiment lift appears on Reports & Billing renewal packet
- Thread is workspace-scoped with audit events
